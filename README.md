**次回以降も問題なく再開できます。**

生徒の手元（PCやタブレット）にダウンロードさせた `.ipynb` ファイルは、Googleドライブを介さずに **Colabへ直接アップロードして再開** できます。

---

### 前回の続きから再開する手順

1. ブラウザで Google Colabのトップページ を開きます。
* URL: `[https://colab.research.google.com/](https://colab.research.google.com/)`


2. 画面に表示されるポップアップ（ノートブックを開く画面）で、**「アップロード」タブ** を選択します。
* ※もしポップアップが出ない場合は、左上メニューの **「ファイル」→「ノートブックをアップロード」** を選択。


3. **「ファイルを選択」** をクリックし、前回の授業でPCに保存した `.ipynb` ファイルを選択します（またはファイルを枠内にドラッグ＆ドロップ）。
4. 前回の続きのコードが読み込まれ、そのまま編集・実行を再開できます。
5. 授業が終わったら、前回同様に **「ファイル」→「.ipynb をダウンロード」** で上書き保存させます。

---

### 授業での注意点

* **「実行状態（変数の中身）」はリセットされる**
* ダウンロードしたファイルには「書いたプログラム」や「出力結果のテキスト・グラフ」は保存されていますが、メモリ上の実行状態（実行中の変数やインポートしたライブラリ）は保持されません。
* 再開時は、上から順にセルを再実行（またはメニューの「ランタイム」→「以降のセルを実行」）するよう伝えておくと混乱が防げます。


* **ファイル名に日付やバージョンを付けさせる（推奨）**
* 毎回同じ名前でダウンロードすると、PC側の仕様で `lesson01 (1).ipynb` のように別名保存され、「どれが最新か分からなくなる」生徒が出やすくなります。
* 「ダウンロードする前に名前を `lesson01_0903.ipynb` のように日付入りに変える」または「前回の古いファイルを整理する」よう案内しておくとスムーズです。
